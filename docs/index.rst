Building Interactive Scientific Dashboards in the Cloud with Plotly Dash
========================================================================

In this workshop, we will dive into Plotly Dash, a powerful framework for building interactive web
applications and dashboards in Python. We will learn how to create and customize Dash applications,
and how to use them to visualize and explore scientific data in real-time. We will also learn how to
deploy a Dash app into production on the Jetstream2 cloud.
