Using Your Jetstream2 Virtual Machine
=====================================

In this module, we will learn to connect to your Jetstream2 virtual machine (VM) using SSH,
and how to use the command line interface (CLI) to manage files and run commands on your VM.
We will also learn how to install necessary software packages and libraries for building interactive
dashboards with Plotly Dash.
